# M&C Abogados

Sitio web del estudio jurídico M&C Abogados (Chiclayo). React + Vite + Tailwind CSS v4.

## Cómo ejecutarlo

    npm install
    npm run dev

Abre http://localhost:8080

## Estructura

- src/main.tsx - punto de entrada de React
- src/App.tsx - componente principal
- src/index.css - estilos globales
- index.html - plantilla HTML
- vite.config.ts - configuración de Vite (React, Tailwind, alias @ para src)
